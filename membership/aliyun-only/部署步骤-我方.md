# OSTAY 会员系统 · 部署步骤（我方操作）

拿到客户的阿里云子账号和邮箱密码后，按顺序做。全程约 1 小时，每做完一步截图给 Claude 确认。

需要用到的文件（都在交付包里）：
- `membership/ostay-members.zip`：会员程序，上传用
- 网站全部文件：上传到 OSS 用
- `admin/index.html`：会员管理页，已包含在网站文件里

---

## A. 登录
用客户给的**子账号登录地址**登录（不是普通的阿里云登录页），输入登录名和密码。

## B. 表格存储（会员名单数据库）· 约 5 分钟
1. 控制台搜索 **表格存储**（Tablestore）→ 首次使用点"开通"。
2. 左上角地域选 **中国香港**。
3. **创建实例**：实例名称 `ostay-members`（字母开头，只能用字母、数字、短横线），其他保持默认 → 确定。
4. 记下实例名称。**表不用建**，程序第一次运行时会自动创建。

## C. 函数计算（会员程序）· 约 15 分钟
1. 控制台搜索 **函数计算 FC 3.0** → 左上角地域选 **中国香港**。
2. **创建函数 → 事件函数**：
   - 函数名称：`ostay-members`
   - 运行环境：**Node.js 20**（没有就选 18）
   - 代码上传方式：**上传 ZIP**，选 `membership/ostay-members.zip`
   - 请求处理程序：`index.handler`
   - 规格：内存 256 MB，执行超时时间 **30 秒**
3. **权限 → 函数角色**：选客户 IT 建好的 `ostay-members-fc`（下拉里没有就手动填 ARN：`acs:ram::<主账号ID>:role/ostay-members-fc`）。
4. **环境变量**，逐行添加：

| 变量名 | 值 |
|---|---|
| `OTS_INSTANCE` | B 步的实例名，例如 `ostay-members` |
| `SMTP_USER` | `vip@ostay.net` |
| `SMTP_PASS` | 客户给的邮箱密码 / 安全密码 |
| `ADMIN_PASSWORD` | 自己设一个管理密码（至少 12 位，交付给客户） |
| `WEBSITE_URL` | 正式网址，例如 `https://www.ostay.net/` |

   可选：`TEAM_EMAILS`（新会员通知发给谁，默认就是 vip@ostay.net，多个用逗号隔开）。
5. **日志**：开启日志功能，日志角色同样选 `ostay-members-fc`（选"自动配置"如果提示要创建角色/没有权限，就改成手动选这个角色）。
6. **触发器 → 创建触发器 → HTTP 触发器**：请求方法勾 POST、GET、OPTIONS；认证方式 **无需认证** → 确定。
7. 复制公网访问地址（`https://….cn-hongkong.fcapp.run`），浏览器打开，看到 `{"ok":true,"service":"OSTAY Members"}` 就成功。

## D. 网站上线（对象存储 OSS）· 约 20 分钟
1. 打开网站文件里的 `content/site.json`，把 C-7 的地址填进 `"membership_endpoint": ""` 的引号中间，保存。
2. 控制台搜索 **对象存储 OSS** → **创建 Bucket**：地域 **中国香港**，读写权限 **公共读**（如提示"阻止公共访问"，先关闭）。
3. Bucket → **数据管理 → 静态页面**：默认首页 `index.html`，子目录首页开启（这样 `/admin/` 能打开）。
4. **上传** 网站全部文件和文件夹到 Bucket 根目录（保持结构）。
5. Bucket → **域名管理 → 绑定域名**：`www.ostay.net`。
   - 域名在阿里云：勾选"自动添加 CNAME 记录"。
   - 在别家：把页面给出的 CNAME 记录发给客户添加。
6. 证书：**数字证书管理服务**申请免费证书（或绑定域名时一并申请），在域名管理里给 `www.ostay.net` 开启 HTTPS。

## E. 测试 · 约 10 分钟
1. 打开 `https://www.ostay.net`，用自己的邮箱注册一次：
   - 邮箱收到欢迎邮件，会员号 OSTAY-00001（第一次请看一下垃圾箱）
   - vip@ostay.net 收到新会员通知
2. 同一个邮箱再注册一次：收到 "Your OSTAY Members ID"，会员号不变。
3. 打开 `https://www.ostay.net/admin/`，输入管理密码，能看到这条记录，能下载 Excel。
4. 有问题：函数计算 → `ostay-members` → **日志**，截图给 Claude。常见：
   - `config_error`：函数没选角色，或 `OTS_INSTANCE` 填错
   - `register_error`：实例名或地域不对（必须都在中国香港）
   - `email_error`：邮箱密码不对，或客户没开 SMTP

## F. 交付
把网站地址、管理页地址、管理密码交给客户，然后让客户停用子账号。
